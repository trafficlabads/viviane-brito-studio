# Viviane Brito

Quero que copie exatamente esse projeto: https://harmonise.framer.website/ obrigatório a cópia de todo o código e componentes, efeitos e efeitos de scroll e navegação, páginas e sub-páginas.

O nome vai mudar para Viviane Brito.

As cores serão de acordo com o documento anexo de paleta de cores

Adapte as sessões para as sessões como no documento anexo SITE HOME.

Mantenha a sessão de artigos, coloque categorias de temas de artigos sendo elas: Artigo, Texto reflexivo, coloque no backend a opção de criar uma categoria. Lá terá o local de criar, editar e excluir artigos do site.

Terá uma sessão de Podcast em áudio e lá vai ter a lista de episódeos. O player terá um design único, ao dar play abre em tela cheia e fica mostrando elementos relaxantes enquanto a pessoa ouve. No backend será possível colocar o link do youtube para ser vinculado a página, será possível colocar os links para a pessoa abrir o Spotify, SoundCloud, YouTube Music, Amazon Music, Apple Music. A logo aparece se tiver link.
Caso a pessoa quiser ver todos os episódeos ela clica em ver todos e abre a página dos podcasts, o design dessa página pode pegar a página Musica do projeto https://lovable.dev/projects/ab2f31fb-e50f-46d6-961f-ebee9bba98a6
